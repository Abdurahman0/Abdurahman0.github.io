Privacy Policy

Last updated: October 31, 2026

The Channel Upload Tool (“the tool”) is a private program that the owner of the YouTube channels UNREALITY LAB and Unsaid runs on his own computer to upload his own videos to those channels. It has no other users.

What the tool accesses

When the owner signs in with Google, the tool asks for two YouTube permissions:

  • Manage your YouTube videos (youtube.upload): to upload videos, set their title, description, thumbnail and scheduled publish time.
  • View your YouTube account (youtube.readonly): to confirm it is connected to the right channel and to check that uploaded videos became public.

It uses the YouTube Data API only for these purposes, only on the owner's own channels.

How data is stored

  • The sign-in token Google returns is stored only on the owner's own computer, in a file readable only by the owner. It is never sent anywhere except to Google when the tool calls the YouTube API.
  • The tool keeps a local record of the videos it uploaded (video ID, title, schedule) to avoid duplicate uploads.
  • No data is stored on any server run by the tool.

Sharing

The tool does not share, sell, rent or transfer any Google user data to anyone. It does not use the data for advertising, and it does not use it to train any AI or machine-learning model.

Google and YouTube

The tool uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

  • Access can be revoked at any time at myaccount.google.com/permissions (or through the Google security settings page). After that the tool can no longer access the channel.
  • Deleting the local token file also ends the tool's access. Any request to delete data can be sent to the contact address below; it will be handled within 7 days.

Changes

If this policy changes, the new version will be posted on this page with a new date.
